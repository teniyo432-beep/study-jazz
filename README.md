# 창가 재즈 (Window Jazz) — 프로토타입

`index.html`을 브라우저로 열면 실행됩니다. 빌드나 설치가 필요 없습니다.

## 화면 구성
- 왼쪽 세로 메뉴: 장면, 날씨, 타이머, 프리셋, 컬러 테마(UI 색만 변경), 전체화면, 언어
- 하단 중앙: 재생바(이전/재생/다음, 최소~최대 볼륨, ♪ 음악 목록)
- 모든 장면은 방 안에서 창밖을 내다보는 사진이고, 날씨(비·눈·천둥)는 창문 영역 안에서만 보입니다.
- 바람과 주변소리(카페 웅성거림 등)는 집중을 위해 제공하지 않습니다.

## 구조
- `data.js` — 장면·곡·날씨·프리셋·테마·UI 문구(ko/en)
- `scenes.js` — 사진/영상 배경과 창문 영역 계산
- `audio.js` — 재즈 재생(파일 또는 합성) + 날씨 효과음 합성
- `app.js`, `style.css`, `index.html` — UI와 상태 저장(localStorage)
- `assets/scenes/` — 장면 사진과 출처 ([README](assets/scenes/README.md))

## 재즈 음원
Kevin MacLeod의 CC BY 4.0 재즈 6곡을 `assets/music/`에 넣어 재생합니다 ([출처](assets/music/README.md)). 음원을 불러오지 못하면 브라우저에서 합성한 재즈로 대체됩니다.
